# KAMU PILIH

Interactive Indonesian horror series on Instagram (@kamupilih.id), produced automatically.

- `engine/`: episode engine. `bash engine/make_episode.sh engine/episodes/partNX.json` -> `out/episodes/KamuPilih_partNX.mp4`
- `engine/docs/RUNBOOK.md`: the daily automatic run
- `engine/docs/STORY_BIBLE.md`: story rules, arc, facts, episode log
- `engine/docs/EPISODE_FORMAT.md`: how an episode file is written
- `videos/`: published Reels (public, used as the upload source for Instagram)
- `kp1/`, `kp2/`: Part 1 and Part 2 sources (narrated versions)
